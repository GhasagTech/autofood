# AutoFood

## الفكرة

منصة محلية تجمع مطاعم حي الخليج المفضلة لديك في مكان واحد، مع طلب مباشر وتجربة أسرع وبنفس أسعار المطاعم.

## المطاعم المشاركة عند الإطلاق

* كسب للمشويات
* لمة بيت العز
* الكبسة الحساوية
* زاد الخليج للأسماك
* السعرات الذهبية
* كرم
* أوقات الحمام
